# About PyBuddy Assistant
PyBuddy Assistant is a RAG chatbot for the PyBuddy Python course. It answers only from the course documents and shows the source of every answer. If something is not in the documents, it says "I don't know".

## What can I ask PyBuddy?
- Course information: class days and times, office hours, weekly topics, project deadlines, the late penalty and the certificate.
- Setup: whether Python is free, which version to install and which editor to use.
- Python basics: variables, data types, lists, loops, range(), functions, try/except and finally.
- Common errors and their fixes: SyntaxError, IndentationError, NameError, TypeError, IndexError, KeyError and ZeroDivisionError.
- Study tips: how to practise, and practice ideas for loops, lists and functions.

## Example questions
- When are the office hours?
- How do I fix a KeyError?
- What does range(5) give?
- What practice idea is suggested for loops?
